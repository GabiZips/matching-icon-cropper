# Security

The app processes images locally. It does not upload artwork, require an account,
or collect analytics. File writes are limited to exported PNG/GIF files at a location
chosen through the native save dialog. Existing paired exports require confirmation
before replacement.

Please report security issues privately using GitHub's **Report a vulnerability**
option in this repository's Security tab. Do not attach personal images or secrets
to a public issue. Include the app version and a minimal reproduction.
